#Vehicle Telemetry Monitoring System

# Project Overview
This project monitors and analyzes vehicle telemetry data such as speed, fuel level, engine temperature, and distance traveled.  
The system stores telemetry data, processes it, and generates visual reports for analysis.

# Objectives
- Collect vehicle telemetry data
- Store data using a database
- Analyze vehicle performance
- Generate visual reports

# Technologies Used
- Python
- SQLite
- Pandas
- Matplotlib
